# Per-story log

One file per story, `S<n>.md`, written by **Alex** after the story is Done.
Five lines is plenty. The point is the fifth one.

```md
# S<n> — <title>
**Asked for:** <your one-sentence intent>
**What came back:** <what the dev agent actually built>
**What QA caught:** <or: nothing, and what you found afterwards yourself>
**What I'd specify differently:** <the AC you wish you'd written>
**Method change:** <what you edited in CLAUDE.md / an agent file / the DoD — or "none">
```

The method file is where this project stops being an app and starts being
transferable. If it says "none" three stories running, either the method is
good or you aren't looking hard enough.
